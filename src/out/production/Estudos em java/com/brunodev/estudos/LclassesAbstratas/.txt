- Classe abstrata: é uma classe que não pode ser instanciada diretamente (não se pode criar objetos dela). Ela serve como um modelo base para subclasses (herança), permitindo definir métodos comuns e métodos abstratos (sem corpo) que as classes filhas são obrigadas a implementar.

- Método abstrato: É um método sem corpo. Utilizado quando uma superclasse precisa definir um comportamento existente, mas a lógica específica desse comportamento só faz sentido ser for definida nas subclasses. Uma classe que possui um método abstrato, tem que ser abstrata. Toda a classe que estende uma classe com métodos abstratos devem sobrescrever esses métodos para que essa classe não seja abstrata.

- Se uma classe abstrata estende outra classe abstrata, não é obrigatório "sobrescrever" os metodos abstratos. Porém, as classes que são filhas são obrigadas. (Exemplo da classe pessoa, funcionário e as filhas de funcionário).
